# EX1 项目规格

## 目标
开发 Windows x64 原生应用 EX1，使用 v2rayN 同款 Xray 内核，提供类似 ProxyOne 的订阅、节点和代理管理体验。应用必须直接启动 UI，不出现终端窗口。

## 功能范围
- 添加、选择、删除订阅；手动并行更新全部订阅；当前订阅单独更新。
- 支持 Clash YAML 的 VLESS + WebSocket + TLS 节点及 VLESS 链接导入。
- 节点列表显示名称、协议、延迟；手动选择节点；自动选择开关开启时禁止手选。
- 自动测速并选择延迟最优节点，当前节点失败时自动切换；后台定时刷新当前订阅。
- 启动/停止 Xray；启用/停用 Windows 系统代理；退出时恢复原系统代理。
- 配置持久化到 `%APPDATA%\EX1`，Xray 使用 `127.0.0.1:10808`，不弹控制台。
- 明亮暖白 + 清亮浅翡翠绿 `#35B97F` 主题，包含加载、空、错误、禁用和运行状态；错误与危险操作保留红色语义。

## 非目标
- 不承诺 Hysteria/Hysteria2、TUN、Android、macOS、ECH、ProxyIP、链式代理。
- 不照搬 v2rayN 全部高级设置，不复制 ProxyOne 全部页面。

## 验收条件
1. `cargo test`、前端类型检查、应用构建全部通过。
2. 添加真实 EdgeTunnel 订阅后能看到节点，手选和自动选择均工作。
3. 启动代理后，经 `127.0.0.1:10808` 请求 YouTube 返回 HTTP 200；停止代理后恢复系统设置。
4. 后台刷新只重选当前订阅；更新全部订阅可并行执行。
5. 最终 exe 启动无终端窗口，真实窗口截图验收。
6. 完成开发记录，GitHub 私有仓库、tag、Release 和 Windows 安装包全部可访问。

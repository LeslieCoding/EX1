# EX1 项目规格

## 目标
开发 Windows x64 原生应用 EX1，使用 v2rayN 同款 Xray 内核，提供类似 ProxyOne 的订阅、节点和代理管理体验。应用必须直接启动 UI，不出现终端窗口。

## 功能范围
- 添加、选择、删除订阅；手动并行更新全部订阅；当前订阅单独更新；后台每 15 分钟并行刷新全部订阅并只重选当前订阅。
- 支持 Clash YAML 与 Base64 URI 订阅，覆盖 VLESS、VMess、Hysteria2；VLESS/VMess 使用 Xray，Hysteria2 使用 mihomo 补充核心。
- 节点列表显示名称、协议、延迟；手动选择节点；自动选择开关开启时禁止手选，应用启动后立即使用已有节点自动选优。Cloudflare“电信/官方优选”名称不按国内落地过滤，节点名称中的“国内官网/中国官网”不参与地区判断，真正的大陆地区节点仍排除。
- 自动测速使用单个 mihomo 测速核心和最多 32 路并行任务，同一节点两次真实探测并发取先成功结果，单次 4 秒超时；不重启当前连接，仅在最佳节点变化时切换一次。
- 启动/停止对应代理核心；启用/停用 Windows 系统代理；退出时恢复原系统代理；核心必须实际监听 10808 后才显示运行成功。
- App 启动、启动/切换代理、停止代理与托盘退出时，必须清理上一实例残留的 EX1 核心并等待退出；只按 EX1 自带核心的真实路径识别，禁止按进程名清理其他代理软件。正常重启时保留当前实例的测速核心，避免干扰并行选优。
- 开机自启动使用 Hidden 计划任务＋无窗口 VBS，不写 Run 键或启动文件夹；静默启动通过 `--silent` 启动 EX1 本体和托盘，仅隐藏主窗口。
- TUN 全局模式通过独立 Hidden＋Highest 的 `EX1TunWorker` 任务运行，开启时停用系统代理并等待核心就绪，关闭时等待旧端口释放后恢复原核心与代理。
- 关闭主窗口仅隐藏到系统托盘，不停止核心或代理；单击托盘图标或再次启动可恢复原进程的普通窗口，禁止全屏和最大化恢复。
- 使用命名互斥体保证单实例；Hidden 计划任务 `EX1Watchdog` 每分钟通过无窗口 VBS 检查进程，退出或异常结束后自动拉起。
- 配置持久化到 `%APPDATA%\EX1`，代理统一使用 `127.0.0.1:10808`，不弹控制台。
- 净白高光奶白背景（`#FFFEFC → #FCFBF7`）+ 浓郁透亮翡翠绿 `#00C271` 主题，卡片带柔和反光，避免灰黄感；包含加载、空、错误、禁用和运行状态，错误与危险操作保留红色语义。
- 应用图标与界面左上角统一使用金属玻璃质感：乳白主体、银绿包边、冷色高光和柔和厚度阴影。

## 非目标
- 不承诺 AnyTLS、Android、macOS、ECH、ProxyIP、链式代理。
- 不照搬 v2rayN 全部高级设置，不复制 ProxyOne 全部页面。

## 验收条件
1. `cargo test`、前端类型检查、应用构建全部通过。
2. 添加真实 EdgeTunnel 订阅后能看到节点，手选和自动选择均工作；KTM001 全部 27 个节点可导入，VMess 与 Hysteria2 各至少一个节点真实连接成功。
3. 启动代理后，经 `127.0.0.1:10808` 请求 YouTube 返回 HTTP 200；停止代理后恢复系统设置。
4. 后台刷新只重选当前订阅；更新全部订阅可并行执行；自动选优期间当前核心 PID 不变、联网正常，结束后无残留测速配置或进程。
5. 最终 exe 启动无终端窗口，真实窗口截图验收。
6. 完成开发记录，GitHub 私有仓库、tag、Release 和 Windows 安装包全部可访问。
7. 开机自启与静默启动任务均为 Hidden，注册表 Run 键和启动文件夹无 EX1；静默任务运行时不显示主窗口；TUN 开关均验证联网和原代理恢复。
8. 关窗后进程和代理保持运行，真实托盘图标可恢复同一 PID 的普通窗口；看门狗为 Hidden 且每分钟运行，强制结束后实测自动拉起并恢复联网。
9. 人工制造上一实例残留的 Xray/Mihomo 后，App 启动能自动清理并恢复代理；启动/切换代理不再误报残留核心占用；停止代理与托盘退出后 EX1 主核心和 10808 监听均释放，其他代理软件进程不受影响。
